# Void Core — Высокопроизводительный веб-сервис

Высокопроизводительный full-stack веб-сервис, спроектированный для работы с минимальной задержкой (low latency) и высокой масштабируемостью. Система использует сверхбыстрый бэкенд на C++ в связке с современным, строго типизированным фронтендом на React. Архитектура полностью контейнеризирована и оркеструется через Docker.

## 🛠 Стек технологий

*   **Backend:** C++20, Oat++ (HTTP-фреймворк)
*   **Frontend:** TypeScript, React, Tailwind CSS, Vite
*   **Database:** PostgreSQL
*   **Infrastructure:** Docker, Nginx (в качестве Reverse Proxy)

---

## 🚀 Архитектура инфраструктуры

Вся экосистема полностью изолирована в контейнерах и готова к продакшену:
*   **Nginx** работает как единая точка входа (reverse proxy), распределяя запросы на контейнер фронтенда и проксируя API-запросы (`/api`) на бэкенд.
*   **Oat++ Бэкенд** обеспечивает молниеносную обработку REST API маршрутов и бизнес-логики.
*   **PostgreSQL** выступает в роли надежной реляционной базы данных для хранения всей информации.

## ⚙️ Установка и развертывание

Выполните следующие шаги для локального запуска проекта через Docker Compose.

### 1. Клонирование репозитория
```bash
git clone https://github.com/arcwagner1337/vcore-web-service
cd vcore-web-service
```

### 2. Настройка переменных окружения (.env)

Вам необходимо создать два отдельных файла `.env` — для сервера и для фронтенда.

#### 🔹 Конфигурация бэкенда
Создайте файл `.env` внутри **папки сервера** (например, `./server/.env`):

```env
# JWT & Безопасность
LOADER_JWT_SECRET=super_secret_key_1337_void_loader
JWT_SECRET=super_secret_key_1337_void_web
SECRET_INVITE_CODE=VOIDCORE_BETA

# Конфигурация базы данных ядра
DB_HOST=localhost
DB_PORT=5432
DB_USER=dev
DB_PASS=vcore_password
DB_NAME=void_core
DB_PASSWORD=vcore_password

# Настройки контейнера PostgreSQL
POSTGRES_USER=dev
POSTGRES_PASSWORD=vcore_password
POSTGRES_DB=void_core

# Настройки SMTP-сендера для отправки уведомлений
SENDER_ADDR=your_email@mail.ru
SENDER_PORT=smtps://smtp.mail.ru:465
SENDER_PASS=ВАШ_СПЕЦИАЛЬНЫЙ_ПАРОЛЬ_ПРИЛОЖЕНИЯ
```

#### 🔹 Конфигурация фронтенда
Создайте файл `.env` внутри **папки фронтенда** (например, `./frontend/.env`):

```env
VITE_API_URL=/api
VITE_LOGIN_ENDPOINT=/users/login
VITE_REG_REQ_ENDPOINT=/users/register-request
VITE_REG_CONF_ENDPOINT=/users/register-confirm
VITE_RESET_REQ_ENDPOINT=/users/reset-request
VITE_RESET_CONF_ENDPOINT=/users/reset-confirm
VITE_ME_ENDPOINT=/api/users/me
VITE_LOGOUT_ENDPOINT=/api/users/logout
VITE_UPDATE_USR_ENDPOINT=/api/users/update
VITE_PURCHASE_ENDPOINT=/api/purchase
```

## 🔑 Инструкция: Получение пароля приложения для Mail.ru

Для работы модуля уведомлений (`SENDER_PASS`) **нельзя** использовать основной пароль от вашей почты Mail.ru. Почтовый сервис заблокирует такие попытки в целях безопасности. Вам необходимо сгенерировать специальный SMTP-токен:

1. Зайдите в свой почтовый ящик Mail.ru через браузер.
2. В левом нижнем углу нажмите на шестеренку (**Настройки**) -> **Все настройки**.
3. Перейдите в раздел **«Безопасность»** -> **«Пароли для внешних приложений»**.
4. Нажмите кнопку **«Добавить»**.
5. Введите название (например, `Void Project Backend`), чтобы понимать, откуда идет доступ.
6. Подтвердите действие основным паролем от почты или кодом из СМС.
7. Mail.ru сгенерирует случайный код из 16 букв (например, `aaaa-bbbb-cccc-dddd`). **Скопируйте его без пробелов** и вставьте в значение `SENDER_PASS=` в файле бэкенда.

### 3. Сборка и запуск через Docker Compose

Чтобы собрать проект из исходников и поднять все контейнеры в фоновом режиме, выполните команду из **корневой папки проекта**:

```bash
docker-compose up -d --build
```


> ⚠️ **Известная проблема (Known Issue):** На этапе инициализации базы данных (init DB) иногда могут возникать конфликты или сбои контейнера, из-за чего сервис может временно упасть после первого запуска. В планах развития проекта этот баг стоит в приоритете на исправление.

После завершения компиляции C++ бэкенда и сборки фронтенда, веб-сервис станет доступен через Nginx (по умолчанию на `http://localhost`).

## ✨ Основной функционал (Features)

На текущий момент в системе реализованы следующие ключевые модули:

*   **Надежная аутентификация (JWT Auth):** Безопасный вход и регистрация пользователей с использованием двух типов JWT-токенов (`JWT_SECRET` для веба и `LOADER_JWT_SECRET` для лоадера).
*   **Верификация через Email:** Регистрация аккаунта требует обязательного подтверждения через отправку токена на указанную почту (SMTP-модуль Mail.ru).
*   **Личный кабинет:** Профиль пользователя с возможностью обновления данных и управления текущим статусом.
*   **Система инвайт-кодов:** Доступ к функционалу и активация подписок временно ограничены секретным кодом (`SECRET_INVITE_CODE=VOIDCORE_BETA`), что идеально подходит для закрытого бета-тестирования.
*   **Интеграция с лоадером:** Наличие выделенных API-маршрутов (endpoints) для безопасной отдачи бинарных файлов (`.sys` драйвера и `.exe` клиентской части) для внешних авторизованных приложений.
